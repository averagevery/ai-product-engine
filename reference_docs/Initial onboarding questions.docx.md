**Onboarding questions (for suggested learning, high level)**

1. **What are you most interested in right now?**

(This determines the first learning category)

Options:

* Buying my first home  
* Saving money  
* Investing  
* Pensions / retirement  
* Paying off debt  
* Understanding money basics

This routes them directly to modules like:

* *First Home Essentials*  
* *Investing Basics*  
* *Debt & Credit*

2. **Which best describes you?**

(This determines life stage)

Options:

* Student  
* Early career  
* Mid career  
* Parent / family  
* Approaching retirement

This helps prioritise modules.

Example:

Student → savings / credit score / renting  
Mid career → pensions / investing

3. **Do you currently have savings?**

Options:

* No savings yet  
* Under £5k  
* £5k–£20k  
* £20k+

This unlocks different learning paths.

Example:

No savings → emergency fund modules  
£20k+ → investing modules

4. **Do you have any of these?**

(multi select)

* Mortgage  
* Student loan  
* Credit card debt  
* Personal loan  
* None

This prioritises debt and borrowing modules.

5. **How confident do you feel with money?**

Options:

* I'm just getting started  
* I know a little  
* I'm fairly confident

This adjusts difficulty:

Beginner → simple foundational questions  
Confident → more advanced modules

**How This Routes Users**

Example user answers:

Goal → Buying first home  
Life stage → Early career  
Savings → £5k–£20k  
Debt → Student loan  
Confidence → Beginner

Their home screen becomes:  
**Start here**  
1️⃣ First Home Essentials  
2️⃣ Saving for a Deposit  
3️⃣ Mortgage Basics  
4️⃣ Credit Scores & Mortgages
