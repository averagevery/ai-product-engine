# Story: Sarah Learns LISA Basics

## Persona

**Persona:** Sarah (First-Time Buyer)

## User Story

As a Sarah (First-Time Buyer), I want to complete a 3-screen micro-lesson explaining Lifetime ISA penalty rules so that I understand the financial consequences before withdrawing for a non-qualifying purpose.

## Acceptance Criteria

- [ ] The lesson consists of exactly 3 screens served from the Firestore `screens` collection
- [ ] Screen 1 presents a quiz question about the LISA early withdrawal penalty (25% government charge) with 4 multiple-choice options
- [ ] Screen 2 presents a quiz question about the LISA age restriction (must be 18-39 to open, withdrawals from age 60) with 4 multiple-choice options
- [ ] Screen 3 displays key takeaways with a Lottie animation using the shield motif (no dollar signs, no red effects)
- [ ] Each screen headline contains 7 words or fewer
- [ ] Each screen body text contains 25 words or fewer
- [ ] Each feedback response contains 15 words or fewer
- [ ] All content uses strict UK English spelling (e.g., "personalised", "organisation")
- [ ] The lesson has a `compliance_audit` field confirming Compliance Agent PASS status before it was published
- [ ] The lesson content does not provide regulated financial advice or recommend specific LISA providers
- [ ] The lesson includes a disclaimer clarifying it is general education, not financial advice

## Notes

This is the first lesson generated by the 9-agent pipeline and serves as the reference implementation for EPIC-001. Sarah's persona was selected because the LISA topic connects directly to the Mulo founder's origin story and her core pain point of not understanding LISA rules. The lesson follows the Layer 2 (LEARN) pattern and should naturally lead to an ATMI insight card (Layer 3: ACT) showing Sarah's personal LISA projection.
